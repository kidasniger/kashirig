Chargement…

1Importer

OBJ : sélectionne aussi le .mtl et la texture. Le modèle doit être en T-pose.

2Contrôle T-pose

En attente d'un modèle.

3Réduction

Cible : triangles (Kidas : 50 000).

4Repères

Les points colorés doivent être sur la tête, le cou, l'entrejambe, les pieds et le bout des mains. Corrige avec les curseurs.

5Squelette

Les 65 os de Kidas sont recalés sur les repères (bleu). Ils suivent les curseurs de l'étape 4.

6Poids

Transfert des poids de Kidas (4 influences max). Fais la réduction (étape 3) avant, puis vérifie avec la pose de test.

7Animations

Animations Mixamo « sans skin » du dossier anim/, jouées sur ton modèle riggé.

Calcule d'abord les poids (étape 6).
